Step 1 — Get your bot

Install it in one line

On a Mac

Open Terminal (⌘+Space, type Terminal, Enter), paste this, press Enter:

curl -fsSL https://raw.githubusercontent.com/andxtrading/andx-trading-bot/main/install.sh | bash
Older Intel Mac

If the Mac command above gives an install error (this can happen on Intel Macs with the newest Python), use this version instead:

curl -fsSL https://raw.githubusercontent.com/andxtrading/andx-bot/main/install.sh | bash
On Windows

Open PowerShell (Start → type PowerShell → Enter), paste this, press Enter:

irm https://raw.githubusercontent.com/andxtrading/andx-trading-bot/main/install.ps1 | iex

Each command downloads the bot, sets it up, and opens it automatically. If Python isn't installed, it tells you where to get it. (Windows: use PowerShell, not Command Prompt.)

Prefer to download and double-click instead?

Download the .zip here, unzip it, then:

1
Mac:

Right-click Start Bot.command → Open → Open. If you only get "Apple could not verify" with Done/Move to Trash: click Done, then → System Settings → Privacy & Security → scroll down → "Open Anyway."

2
Windows:

Double-click Start Bot (Windows).bat. If a blue box appears, click "More info → Run anyway."

Step 2 — Compete

Make the bot your own

1
Press "Start bot."

The dashboard opens in your browser on practice money — no account or keys needed.

2
Open the "Edit Strategy" tab.

Change the bot's code, hit Save & Apply, and it runs your strategy. Broken code is refused, so you can't break it.

3
Add your name and climb.

Everyone starts from the same bot — the better your strategy, the higher you place.

Safe by default. It starts in paper mode — simulated money, real prices. Add your own ANDX keys only when you choose to trade live; your keys stay on your computer and are never uploaded.

Each competitor runs their own copy with their own keys — nothing is shared. Crypto trading carries real risk; start in practice mode. · View the code on GitHub
